You are about to build a phone agent for a clinic from its guidelines. Before
drawing anything, find what the guidelines leave open.

Ask a question only when the guidelines leave a real gap that changes how the
agent behaves on calls that will happen: what to do when none of the offered
times works, what to check before opening a patient's chart, whether it can
book for someone else. Not wording, not things the guidelines answer, not
rare corner cases. Ask 0 to 3 questions; 0 is a good answer when nothing
important is open.

Each question is short and addressed to the clinic ("What should the agent do
when neither time works for the caller?"), with 2 or 3 options the clinic can
pick as they are: short, concrete, each a different way to behave.
